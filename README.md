# Palmang Kultur

Create a complete, modern and visually distinctive website for:

PALMANG KULTURFORENING

The entire website must be written in NORWEGIAN.

Palmang Kulturforening is a Norwegian cultural association that works to preserve, present and share Palestinian culture, identity and cultural heritage in Norway.

The website must have a STRONG PALESTINIAN CULTURAL STYLE combined with clean, modern Scandinavian web design.

This should NOT look like a generic company website.

The visitor should immediately feel:

- Palestinian culture
- Palestinian heritage
- Community
- Warmth
- Tradition
- Art
- History
- Identity
- Hospitality
- Cultural pride
- Norwegian-Palestinian cultural exchange

IMPORTANT:
The design should focus on Palestinian CULTURE and HERITAGE, not political activism.

OVERALL VISUAL STYLE
==================================================

Create a sophisticated visual identity inspired by Palestine.

- Palestinian tatreez embroidery
- Traditional Palestinian geometric patterns

- Traditional crafts

- Warm cream / ivory
